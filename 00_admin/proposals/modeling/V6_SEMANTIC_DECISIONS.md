## D1：如何消除 `β=0` 尺度退化

必须三选一：

1. **固定 `β=1`（建议，且与 README 的 support 下界一致）**：直接逼近式 (3) 的单位化 `F_N`。
2. **保留可变 `β`，改用尺度不变误差**：要求 `β≠0`，以 `||βF_N-B||_F/(N|β|)` 作为精度；需同时规定 `β` 的数值下界与实现输出缩放。
3. **保留原式并固定产品能量**：例如规定 `||B||_F=||F_N||_F=√N` 后优化实 `β`；离散因子下可行性需另验。

不能只选“`β>0`”：`β→0+` 与零乘积仍使误差下确界退化为 0。

## D2：Q5 的目标顺序

必须三选一：

1. **词典序最小化 `(C,K,RMSE)`（建议，能够定义 README 的 `K*`）**：先满足 `RMSE≤0.1`，再最小 `C`，再最小 `K`，最后最小 RMSE。
2. **只最小化 `(C,RMSE)`**：`K` 仅报告，不声称 `K*=5`。
3. **报告 `(C,K,RMSE)` Pareto 前沿**：不选唯一 `K*`，除非用户再指定最终偏好。

同时请选择：当 `L=0` 导致多个 `q` 都有 `C=0` 时，是再最小化 `q`，还是只把 `q=1` 称为“一个最优选择”而非 `q*`。

## D3：DFT 与 RMSE 归一化

必须二选一：

1. **采用题面式 (3)（建议）**：`F_N=N^{-1/2}[e^{-j2πkn/N}]`，RMSE=`||目标-B||_F/N`。README 的 `√(N-s)/N` 下界与此一致。
2. **采用题面式 (1)**：未归一化 DFT；需重算全部阈值、下界与 V5/V6 数字，现有数字不可沿用。

复数范数统一使用 `Σ|z|²`，索引统一从 0 开始。

## D4：`q/P_q/L` 的计数口径

必须确认以下整组定义，或给出替代定义：

- `q∈Z_{≥1}`；`P_q={0,±2^r:r=0,…,q-1}`，因此 `P_1={0,±1}`。
- `L` 是按因子链作用于输入向量时，所有层中非平凡常数乘法节点的总数；不显式形成 `A_1…A_K`。
- 系数 `0,±1,±j,±1±j` 按题面免费；每个非免费系数出现位置计一次，不做跨行/跨层硬件共享。
- 排列/索引重排不计复乘，但必须记录；任何对角或其他含非免费系数的层都按同一规则计数。

若改用“显式矩阵乘积复乘数”或“物理共享乘法器数”，README 的 `L=0` 证书必须作废并重算。

## D5：`K` 的层数边界

必须二选一：

1. **所有支持可能扩张的 `N×N` 线性层均计入 `K`（建议）**；纯排列可独立记录但不增加支持，标量 `β` 不计层。
2. **允许某些层不计入 `K`**：必须逐类列出免费层并重新证明支持上界；存在未计数稠密层时不得使用 `2^K` 证书。

同时确认 `K` 为正整数；若允许 `K=0`，须明确空乘积定义与是否纳入搜索。
