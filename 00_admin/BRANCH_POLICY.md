# 分支与合并策略

## 长期分支

- `main`：唯一集成分支，始终保持可复现。
- `agent/modeling`：题意、检索、模型和冻结协议。
- `agent/compute`：代码、测试、运行清单和冻结结果。
- `agent/paper`：论文、编译、复现和验收证据。

## 集成检查

合并前由集成者检查：写入范围、handoff 完整性、测试/门禁、输入哈希、是否修改冻结内容。发生冲突时不让后一个 Agent 直接覆盖，先在 `DECISIONS.md` 记录裁决。

建议使用 `--no-ff` 合并保留角色边界；每次只合并一个已交接提交单元。集成完成后，其他 Agent 通过 merge/rebase 最新 `main` 获取共享状态，但不得直接读取另一个 Agent 的未集成分支作为正式输入。
