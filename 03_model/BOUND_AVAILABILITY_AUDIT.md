## 3. 证伪的两类结构不等式

### 3.1 列支持传播（证伪）

曾试图把行支持论证原样搬到列上，得到 `col_support(P) ≤ min(N, 2^K)`。随机行二稀疏乘积复算（`N ∈ {8,16,32}`，`K ∈ {1,2,3,4}`，每个组合 12 次试验）：

| N | K=1 | K=2 | K=3 | K=4 | 曾猜的 cap |
| --- | --- | --- | --- | --- | --- |
| 8 | 5 | 8 | 8 | 8 | 2 / 4 / 8 / 8 |
| 16 | 7 | 12 | 14 | 15 | 2 / 4 / 8 / 16 |
| 32 | 6 | 17 | 21 | 25 | 2 / 4 / 8 / 16 |

`N=16, K=2` 观测到列支持 12 > cap 4，命题被直接推翻。原因：行界来自**最右**因子的行支持，列界由**最左**因子支配，而左因子的列可以覆盖很多行（`N/2` 行各带 2 个非零即可覆盖全部列两次）。故本命题不可用，已记入 `structural_bounds_results.json` 的 `falsified`。

### 3.2 计数式收紧（无效）

由行支持得 `nnz(P) ≤ N·min(N, 2^K)`，再配合"目标无零元 ⇒ 每个零位置贡献 `1/N` 平方误差"，得到

```
RMSE ≥ sqrt(1 − nnz(P)/N²) ≥ sqrt(N − min(N,2^K))/N
```

两个不等式**同源**：`nnz` 界完全来自行支持界，所以计数式永不比支持界更紧；当 `min(N,2^K) = N` 时两者同时退化为 0。因此"用计数收紧大 `K` 的下界"这条路走不通。

## 4. 系数幅值证书：正确但平凡

**命题（正确）**：若每个因子元素的实部与虚部都属于 `P_q`，则每个因子元素模长 ≤ `m_q = √2·2^{q-1}`；乘积 `P` 的一行是最右因子至多 2 行的线性组合，系数模长各 ≤ `m_q`，故

```
|P[i,j]| ≤ 2·m_q =: cap2
```

对等模目标（`|T[i,j]| = 1/√N`），一个"每行至多 `M = min(N,2^K)` 个非零、且每项模长 ≤ `cap2`"的松弛，其逐行最优值（取模长最大的 `M` 个位置并饱和其模长，相位自由）给出精确下界：

```
err² ≥ (N − M)/N + M·max(0, 1/√N − min(cap2, 1/√N))²
```

**为什么平凡**：`cap2` 的最小值出现在 `q=1`，为 `2√2 ≈ 2.828`；而注册实例中 `|T| = 1/√N ≤ 0.7071`。故 `cap2 > |T|` **对所有注册的 `(N, q)` 成立**，第二项恒为 0，证书退化为第 3.2 节的计数式，即与支持界等价。`verify_row_relaxation_bounds.py` 的 `certificate_a_active_cases = []` 即为该事实的机器记录。

## 6. 对论文与对擂的直接影响

1. **问题 5 的 `K*` 不能作为全局最优声明**。用户 V6 材料声称的 `K*=5` 只在"固定 `β=1` 且只用支持界"的口径下成立：支持界保证 `K ≥ 5` 只是"`K ≤ 4` 不可行"，而 `K ≥ 6` 处在下界为 0 的区域。若 `K=6` 也存在 `RMSE ≤ 0.1` 的可行解，`(C,K,RMSE)` 字典序才会因 `K` 更大而判 `K=5` 更优——这需要 `K=5` 可行**且** `K=6` 在 `C` 上不更优；`C` 的判据先于 `K`，故若某个 `K=6` 方案达到更小的 `C`，它反而会胜出。因此论文只能写"在给定协议预算内 `K=5` 为最优可行"，不能写"`K*=5` 已被证明"。
2. **问题 2 完全没有下界**：计算 Agent 的 q2 结果只能是启发式最好值，论文不得出现任何 q2 最优性措辞。
3. **搜索剪枝**：`N=32` 的 q3/q4 可安全跳过 `K ≤ 4`，`N=64` 的 q5 可跳过 `K ≤ 4`（若协议的 K 网格包含它们）。这不改变协议，只是省预算。
4. **`best_found` 之外的措辞都缺证据**：本审计未发现任何能替代支持界的新证书，故 §6.1–6.3 的边界即为当前可声称的全部。
