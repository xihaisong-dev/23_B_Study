## 2. `β=0` 退化审计

**标签：待语义裁决；同时阻断所有最优性证书。**

题面式 (6) 按当前提取为

\[
\min_{\mathcal A,\beta}\frac1N
\left\|\beta F_N-A_1\cdots A_K\right\|_F,
\qquad \beta\in\mathbb R.
\]

若没有额外归一化，取 `β=0`，并令任一因子为零矩阵，则矩阵乘积为零，RMSE 恰为 0。零矩阵满足每行至多两个非零元素，也满足离散系数约束；按题面对零乘法的豁免，`L=0`。即使只补充 `β>0`，取 `β→0+` 与零乘积仍会令目标下确界趋于 0，因此仅要求非零或正 `β` 仍不足以消除尺度退化。

README 的 support 下界没有 `|β|`，实际等价于额外采用 `β=1` 或其他固定尺度。README 没有说明这一步与题面式 (6) 如何兼容。因此：

- 按题面字面口径，README 的非零 RMSE 下界不成立，问题会被平凡零解主导；
- 按 `β=1` 口径，support 下界可以使用，但这是必须显式记录的语义裁决；
- 若保留可变 `β`，必须采用能固定尺度的等价规范，例如固定产品范数，或把误差改成除以 `|β|` 的相对尺度误差；具体选择不能由建模 Agent 静默决定。

## 3. support 下界的成立条件

**标签：定理本身可数学复核；应用到 README 结论前待语义裁决。**

### 3.1 行支持传播

假设所有因子均为同一尺寸的 `N×N` 矩阵，且每个因子的每行至多两个非零元素。对任意两个矩阵 `A,B`，`AB` 的第 `i` 行是 `B` 中至多两个行向量的线性组合。因此，若 `B` 每行支持数至多 `s`，则 `AB` 每行支持数至多 `2s`。归纳得到

\[
\left|\operatorname{supp}\left((A_1\cdots A_K)_{i,:}\right)\right|
\le \min(N,2^K).
\]

该上界不要求系数属于 `P_q`，所以在固定矩阵维度与层数口径后，它对更宽松的连续系数类也成立。若算法在 `K` 之外允许未计数的稠密变换、维度扩张/收缩或支持扩张层，则上述证明不能直接套用；纯排列不会增加支持数，但必须说明是否计入 `K`。

### 3.2 与单位化 DFT 的误差下界

题面式 (3) 的单位化 DFT 每个元素模长为 `1/√N`。若矩阵 `B` 每行至多 `s` 个非零元素，则每行至少有 `N-s` 个位置只能以零逼近目标。于是

\[
\|F_N-B\|_F^2\ge N-s,
\qquad
\frac1N\|F_N-B\|_F\ge\frac{\sqrt{N-s}}N.
\]

对题面原式的 `βF_N`，正确的同类下界是

\[
\frac1N\|\beta F_N-B\|_F
\ge |\beta|\frac{\sqrt{N-s}}N,
\]

而不是 README 中省略 `|β|` 的式子。只有固定 `|β|=1`（README 实际使用 `β=1`）时，两者相同。

### 3.3 `N=64` 算术核对

在 `β=1`、单位化 `F_64`、所有支持扩张因子都计入 `K` 的前提下：

- `K=4` 时，`s≤16`，下界为 `√48/64 = 0.10825317547305482 > 0.1`；因此这组前提下任何 `K≤4` 的方案都不满足阈值。
- `K=5` 时，`s≤32`，下界为 `√32/64 = 0.08838834764831845`。
- README 给出的上界 `0.09049305675445285` 与该下界之差为 `0.002104709106134403`，算术正确。
- README 的 `2.325823860548105%` 使用“差值/上界”作为分母；若使用常见的“差值/下界”，则为约 `2.38120653019634%`。正式文稿必须命名分母，不能只写“relative gap”。

这里证明的是一个下界，不是固定 `K=5` 时全局最优值。README 对此最后一句的限定是正确的，但其“可行上界”仍需工程复现。

## 4. `q=1`、`L=0` 与 `C=0` 审计

**标签：集合推论可数学复核；`q` 域和 `L` 口径待语义裁决；具体解待工程复现。**

若裁决 `q∈Z_{≥1}` 且

\[
P_q=\{0,\pm 2^r:r=0,\ldots,q-1\},
\]

则 `q=1` 时 `P_1={0,±1}`，可用复系数恰为

\[
\{0,\pm1,\pm j,\pm1\pm j\}.
\]

它们全部位于题面明确豁免的乘法集合中。因此，如果 `L` 定义为对输入向量逐层执行 `A_Kx,…,A_1(·)` 时，各因子内非平凡常数乘法的总数，那么任意只含上述元素的因子链都有 `L=0`，从而 `C=qL=0`。这是条件性的数学推论。

仍有四个问题未解决：

1. 题面没有显式写出 Q5 中 `q` 必须是正整数及其上下界；`q=1` 看似符合示例延拓，但尚未由官方来源或用户裁决确认。
2. 题面给出的 2×2“矩阵乘矩阵”计数示例可能使人把 `L` 解释为显式形成矩阵乘积时的复乘数。此口径下，两个“免费常数”的乘积可能产生 `±2` 或 `±2j`，`L=0` 不再自动成立。
3. 若硬件允许常数共享、公共子表达式或复用乘法器，`L` 还可能是物理乘法器数而不是运算图中的常数乘法节点数。
4. 在 `L=0` 时，任何允许的 `q` 都给出 `C=0`；若目标仅是最小化 `C`，则 `q=1` 是一个最优选择但未必是唯一的 `q*`。若要声称最小 `q`，目标中还须加入 `q` 的平局规则。

README 没有提供五个 `q=1,K=5` 因子，因此“已有 `L=0` 可行解”尚不能验证。

## 5. `K*=5` 的目标定义审计

**标签：待语义裁决 + 待工程复现。**

README 自行提出词典序目标：先最小 `C`，再在最小 `C` 下最小 `K`，最后在最小 `(C,K)` 下最小 RMSE。题面 Q5 明确要求 `RMSE≤0.1` 并使 `C` 尽量低，但没有明确把 `K` 设为第二层目标，也没有给出 RMSE 的最终平局顺序。因此 `K*=5` 只在采用 README 的词典序定义后才是有定义的命题。

在以下全部条件成立时，`K*=5` 的证明结构是有效的：

1. 固定单位化 `F_64` 与 `β=1`；
2. 所有支持扩张层均为 `64×64`、每行至多两个非零，且全部计入 `K`；
3. 目标确认为“先满足 RMSE≤0.1，再在最小 `C` 下最小 `K`”；
4. 存在一个经复算合格的 `K=5,C=0,RMSE≤0.1` 因子链。

support 下界提供第 4 点所需的“`K≤4` 不可行”半边证明，但 README 缺少因子，无法验证“`K=5` 存在”半边。当前最多可写成：**若 V5 因子经复现可行，则在选定语义下 `K=5` 达到支持下界允许的最小层数。**

若正式目标只最小化 `C`，那么任何满足阈值且 `C=0` 的层数都是成本最优，不能单独称 `K*=5`。若把延迟、加法数、存储或层数纳入硬件成本，目标和证书还需重做。

## 6. RMSE 归一化审计

**标签：公式算术可数学复核；DFT 规范待语义裁决。**

README 的 `√(N-2^K)/N` 与题面式 (3) 的单位化 DFT、题面式 (6) 的 `1/N` Frobenius 归一化相容。它不与题面式 (1) 的未归一化标量 DFT 相容：若目标矩阵元素模长为 1，则相同支持论证给出的下界为 `√((N-s)/N)`。

因此，README 的全部 RMSE 数字至少隐含：

- 目标是式 (3) 的 `F_N`，每个元素模长 `1/√N`；
- RMSE 计算为 `||目标-乘积||_F/N`，而不是再除以 `√N` 或按单行计算；
- 目标尺度相当于 `β=1`；
- 复数 Frobenius 范数使用模平方 `|z|^2`。

正式复现必须把这些选项写入配置，并同时报告独立复算公式。若采用其他 `β` 或未归一化 DFT，README 数字不可横向比较。

## 8. 分层结论

### 可数学复核

- 行二稀疏 `K` 层乘积的每行支持数至多 `2^K`，前提是所有支持扩张层均为同尺寸因子并计入 `K`。
- 对单位化 DFT、`β=1`，RMSE 下界为 `√(N-min(N,2^K))/N`。
- `N=64` 下 K=4/K=5 的下界值、README 的 absolute gap 算术正确。
- 在 `q=1` 集合与“逐因子作用于向量”的计数口径下，所有允许系数均免费，因此 `L=0`。

### 待语义裁决

- 如何消除 `β=0`/尺度退化；是否固定 `β=1`。
- 采用式 (3) 的单位化 DFT 还是式 (1) 的未归一化 DFT。
- Q5 是否采用 `(C,K,RMSE)` 词典序，以及是否把 `q` 纳入平局规则。
- `q` 的整数域、`P_q` 的精确定义和 `L` 的运算图/硬件计数边界。
- 哪些层计入 `K`，是否允许未计数的排列、对角或其他变换。

### 待工程复现

- V5 因子是否真实存在并满足 `q=1,K=5,L=0,RMSE≤0.1`。
- V5 的 RMSE、当前最好地位以及由其支撑的 `C*=0`/`K*=5` 存在性证书。
- V6 代码是否实现所述搜索、是否正确测试，以及是否确实未找到更优可行值。

在语义裁决和工程复现都完成前，V5/V6 只能作为候选思路来源，不能进入正式 `metrics.json`、论文摘要或最优性结论。
