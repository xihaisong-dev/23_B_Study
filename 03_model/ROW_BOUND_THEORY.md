## 0. 前提与记号

- 目标矩阵取题面式 (3) 的单位化 DFT：`F_N = N^{-1/2}[e^{-2πi·row·col/N}]`，`N = 2^t`。
- 乘积 `B = A_1 A_2 ⋯ A_K`，所有 `A_k` 为 `N×N` 复矩阵，按 `A_1` 先作用、`A_K` 后作用的顺序连乘。
- 误差按题面式 (6)：`RMSE = (1/N)‖βF_N − B‖_F`，复数范数用 `Σ|z|²`。
- 约束 1：每个 `A_k` 的每行至多 2 个非零元。
- 约束 2：`A_k[l,m] = x + jy`，`x, y ∈ P_q`。题面把 `P_q` 既写成 `{0,±1,±2,…,±2^{q-1}}`，又给出 `P={0,±1,±2,±4} ⇒ q=3`；本文件采用与 `q=3` 示例一致且能被省略号支持的读取
  `P_q = {0, ±1, ±2, …, ±2^{q-1}}`（即整段整数，不是仅取二次幂），因此
  `P_1 = {0,±1}`、`P_2 = {0,±1,±2}`、`P_3 = {0,±1,±2,±3,±4}`。
  **该读取仍属待裁决语义**（见 `01_problem/PROBLEM_STATEMENT_AUDIT.md` A4 与 `00_admin/proposals/modeling/V6_SEMANTIC_DECISIONS.md` D4）。
- `L`：按题面附录一，与 `0, ±1, ±j, (±1±j)` 相乘不计复乘，其余常数乘法计一次。
- 免费集合记作 `E = {0, ±1, ±j, ±1±j}`。

## 2. T1 行支持传播（定理，含随机复算）

若每个因子的每行至多 `r` 个非零元，则乘积 `A_1⋯A_K` 的每行至多 `min(N, r^K)` 个非零元。

**证明**：`A_1⋯A_K` 的第 `i` 行是 `A_2⋯A_K` 中至多 `r` 行的线性组合，归纳即得 `r^K` 的行支持上界。

随机复算（`N=16`，每层随机行二稀疏整数矩阵，各 20 次试验）：

| K | 观测最大行支持 | 上界 `min(N,2^K)` |
| --- | --- | --- |
| 1 | 2 | 2 |
| 2 | 4 | 4 |
| 3 | 8 | 8 |
| 4 | 11 | 16 |

**注意（本轮修正）**：行二稀疏**不蕴涵**秩上界 `2^K`。单个行二稀疏矩阵可以满秩（例如排列矩阵），因此"秩 ≤ 2^K"是错误命题；正确的秩事实只有 `rank(AB) ≤ min(rank A, rank B)`（脚本同时用随机试验核对了这一条，无违例）。本文件不再使用任何基于 `rank ≤ 2^K` 的论证。

## 3. T4 精确构造（本题问题 1 的严格可行解族）

对 `N = 2^t`，令 `b = bitrev_t`，定义

- `P`：`P[i][b(i)] = 1`（比特反转排列，每行 1 个非零元）；
- `C_ℓ`（`ℓ = 1..t`）：块大小 `2^ℓ` 的蝶形层，
  `C_ℓ[start+k][start+k] = 1`、`C_ℓ[start+k][start+k+2^{ℓ-1}] = w`、
  `C_ℓ[start+k+2^{ℓ-1}][start+k] = 1`、`C_ℓ[start+k+2^{ℓ-1}][start+k+2^{ℓ-1}] = −w`，
  其中 `w = exp(−2πik/2^ℓ)`、`k = 0..2^{ℓ-1}−1`。每行恰好 2 个非零元。

则 `C_t ⋯ C_1 P = √N · F_N`（未归一化 DFT）。把每个因子统一除以
`d = (√N / (1/√N))^{1/(t+1)}` 后，乘积恰为 `β F_N`，`β = 1/√N`。

复算结果（脚本 T4 段，`max|chain − βF_N|` 为逐元素最大绝对误差）：

| N | t | K = t+1 | `max|chain − βF_N|` | RMSE | β | 每行支持 | L | C = 16L |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2 | 1 | 2 | `6.1e-17` | `3.1e-17` | 0.707107 | 2 | 0 | 0 |
| 4 | 2 | 3 | `1.2e-16` | `5.0e-17` | 0.5 | 2 | 2 | 32 |
| 8 | 3 | 4 | `5.0e-16` | `1.1e-16` | 0.353553 | 2 | 10 | 160 |
| 16 | 4 | 5 | `9.5e-16` | `1.7e-16` | 0.25 | 2 | 34 | 544 |
| 32 | 5 | 6 | `9.9e-16` | `1.7e-16` | 0.176777 | 2 | 98 | 1568 |
| 64 | 6 | 7 | `1.0e-15` | `1.7e-16` | 0.125 | 2 | 258 | 4128 |

（`L` 为保守的位置计数；`C = qL` 取 `q = 16`，即问题 1 的默认值。）

结论（问题 1，仅约束 1）：

1. **存在精确解**：`RMSE = 0`（数值上 `< 1e-15`，为浮点精度极限）在 `t=1..6` 的每个尺寸上用一个统一构造实现。
2. `K = t+1 = log₂N + 1`，`β = 1/√N`，最小误差为 0；因此问题 1 的"最小误差"在 `N ≤ 64` 上取到 0，剩下的只是一个约束/复杂度层面的优化问题。
3. `L` 的实测值严格按题面附录一的豁免规则统计（对**未缩放**的整数/单位根因子计数；一旦乘上归一化常数，所有元素都不再等于豁免集合，计数将失去意义）。实测值满足
   `L = N(t−1) − 4(N−1)/3`（见上表，`t≥3` 时逐项吻合）。
   `L` 计的是**矩阵位置数**：例如 `N=8` 的第三层有 3 个不同扭因子，但每个扭因子同时以 `w` 和 `−w` 出现在两行，故位置数为 6，全链合计 10。硬件若共享取负（一个乘法器加一次符号翻转），可将其减半为 5。题面对 `L` 的定义不足以区分这两种读法，因此本表给出**保守的位置计数**，并同时给出"共享取负"列。这正是 `V6_SEMANTIC_DECISIONS.md` D4 必须裁决的第三项。
4. 是否可以做到 `K = t`：`NOT_RUN`。`t` 是本构造的下界猜想（`F_N` 可逆，行二稀疏因子在每行的两个非零列上受限），但本轮**没有证明**，脚本中不声称。

## 4. T5 支持下界（β = 1，与 `q` 无关）

对任意满足约束 1 的乘积 `B`，其每行最多 `M = min(N, 2^K)` 个非零元。单位化 `F_N` 的每个元素模长为 `1/√N`，因此每一行至少有 `N − M` 个位置只能留空：

```
(1/N)‖F_N − B‖_F ≥ sqrt(N − M)/N,        M = min(N, 2^K)
```

更精确的逐行形式（脚本按行精确计算，未使用 `1/√N` 的均匀性近似）：第 `i` 行的下界是"把前 `M` 个最大模值之外的质量全部计入残差"，即 `Σ_{秩 > M} |y_j|²`。该形式对 `F_N` 与 `F_4 ⊗ F_8` 都成立，因为没有用到 DFT 的行等模性质。

| N | K=3 | K=4 | K=5 | K=6 | 使下界失效的临界 `M`（`N − 0.01N²`） |
| --- | --- | --- | --- | --- | --- |
| 8 | 0 | 0 | 0 | 0 | 7.36 |
| 16 | 0.176777 | 0 | 0 | 0 | 13.44 |
| 32 | 0.153093 | 0.125000 | 0 | 0 | 21.76 |
| 64 | 0.116927 | 0.108253 | 0.088388 | 0 | 23.04 |

可用于 `RMSE ≤ 0.1` 的推论（**只在 `β = 1` 口径下成立**）：

- `N = 32`、`K ≤ 4`（`M ≤ 16 < 21.76`）时下界 `≥ 0.125 > 0.1`，因此必须 `K ≥ 5`。
- `N = 64`、`K ≤ 4`（`M ≤ 16 < 23.04`）时下界 `0.108253 > 0.1`，因此必须 `K ≥ 5`；`K = 5` 时下界 `0.088388`，不再是障碍。
- `N = 64`、`K ≥ 6`（`M = 64`）时该下界退化为 0，**不能**据此排除 `K ≥ 6` 的方案。

这解释了 README 的 `K* = 5` 的确切性质：它是"在 `β = 1` 归一化下、且只用支持论证"得出的结论，不是对题面式 (6) 的无条件结论。

## 5. T6 尺度退化（为什么 `K*`/`C*` 必须附带归一化约定）

把每个因子乘 `c`、同时把 `β` 乘 `c`，乘积与"按 `β` 缩放的目标"同时缩放 `c`，残差按 `c` 线性缩放。脚本对 `N=8` 的归一化精确链复算：

| c | β' | RMSE | 是否等于 `c × 参考值` |
| --- | --- | --- | --- |
| 1 | 0.353553 | `1.079e-16` | 参考 |
| 2 | 0.707107 | `2.158e-16` | 是 |
| 0.5 | 0.176777 | `5.395e-17` | 是 |
| 0.001 | 0.000354 | `1.097e-19` | 是 |

因此式 (6) 关于 `(𝒜, β)` 的下确界为 0（取 `c → 0`）。任何"最小 `K`""最小 `C`"的陈述都必须先固定 `β` 的口径（典型选择：`β = 1`、或 `β = 1/√N`、或相对误差 `‖βF − B‖_F/(N|β|)`）。这是主 Agent 必须在 `DECISIONS.md` 里落盘的第一项。

## 6. 问题 4 的目标矩阵事实（补充核查）

`F_4 ⊗ F_8` 的形状是 `32×32`，元素为 `(1/√32)e^{-2πi(a b/4 + c d/8)}`，其中行指标 `(a,c)`、列指标 `(b,d)`。由混合乘积公式

```
(F_4 ⊗ F_8)(F_4 ⊗ F_8)^H = (F_4 F_4^H) ⊗ (F_8 F_8^H) = I_4 ⊗ I_8 = I_32
```

可知它仍是酉矩阵（脚本 T0：残差 `7.0e-16`）。

- **不是** `F_32`：`F_32[row][col] = (1/√32)e^{-2πi·row·col/32}` 是单一乘积的频率索引，而 `F_4⊗F_8` 的相位是 `(ab/4 + cd/8)` 的两段和。题面"注意 `F_N` 非 DFT 矩阵"的提示因此是必要且正确的，不是勘误。
- 与"必须用 `F_32` 替换"的误解相反，问题 4 的优化目标就是 `F_4⊗F_8` 本身。
- 每一行的模值仍然全为 `1/√32`，所以第 4 节的支持下界形式对它同样适用；脚本对 `F_32` 与 `F_4⊗F_8` 两个目标分别计算，`N=32` 的数值恰好相同（两者行模值相同且行内相位变化不影响该下界的取值）。

## 7. 问题 5 的证书现状（重要限制）

脚本**不使用**任何幅值上限技巧：`|A_k[l,m]| ≤ √2·2^{q-1}` 只能逐项约束因子元素，经过 `K` 次连乘后被因子内部的和式放大（例如 `K=2, q=1` 时可观察到 `|B| = 14.56`，远超 `2`）。任何由此推出的下界都是无效的，因此本文不给出 `q` 与 `K` 联立的下界。

当前可用于问题 5 的严格陈述只有：

1. 第 4 节的精确构造给出 `RMSE = 0`，其系数为 `±1, ±j` 级别（`β` 为常数可单独提取），因此**每个尺寸都存在 `C = 0` 的精确解**（`L=0` 需要所有非零元素都在豁免集合内；本构造的扭因子层含 `w ∉ E`，其 `L` 见上表；把这些 `w` 用 `±1,±j,±1±j` 近似后是否仍能保持 `RMSE ≤ 0.1` 且 `L = 0`，属计算 Agent 的搜索任务）。
2. 第 4 节的精确构造给出 `RMSE ≤ 0.1` 的**可行上界**：`K = t+1`，且对 `q=1` 也成立（`β` 可提出，因子系数为整数/单位根）。
3. 对固定 `K`、`q` 的**下界**：目前只有第 4 节的 `β=1` 支持下界有效，它在 `M = N` 时退化，不能用于排除 `K ≥ 6` 的方案。

因此 README 的 `RMSE = 0.09049305675445285`（V5）在本仓库仍为 `UNVERIFIED`，本文不引用它作为上界或下界。
