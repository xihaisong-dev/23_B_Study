# 问题 5：高斯整数格不可行性证书

## 结论

在冻结协议的 `beta=1`、单位化 DFT 与离散系数定义下，对任意正整数 `q`、任意因子数 `K`、任意满足约束 2 的因子链以及任意右置换，乘积矩阵的每个元素都是高斯整数。令

\[
d_N=\min\left\{\frac1{\sqrt N},\ 1-\frac1{\sqrt N}\right\}.
\]

则

\[
\operatorname{RMSE}(F_N,B)=\frac{\lVert F_N-B\rVert_F}{N}\ge d_N.
\]

对冻结的 Q5 注册尺寸 `N in {2,4,8,16,32,64}`，最小下界为 `d_64=1/8=0.125>0.1`。因此这些注册实例的可行域全为空；这个结论与搜索算法、种子、预算、`q`、`K`、行二支持及候选编号无关。

这里的“全局不可行”严格限定为**冻结协议的六个有限实例上、对全部合法因子的全局结论**，不是对题面 `t=1,2,3,...` 的无限尺寸族外推。对 `N>=128`，本证书的下界已经不大于 `0.1`；事实上全零乘积的 RMSE 为 `1/sqrt(N)`，故不能据本证书声称无限尺寸族不可行。

## 2. 高斯整数闭包

记高斯整数环为

\[
\mathbb Z[i]=\{a+ib:a,b\in\mathbb Z\}.
\]

由于 `P_q` 的元素均为整数，每个合法因子 `A_k` 的每个元素都属于 `Z[i]`。若 `u=a+ib`、`v=c+id` 属于 `Z[i]`，则

\[
u+v=(a+c)+i(b+d),\qquad
uv=(ac-bd)+i(ad+bc)
\]

仍属于 `Z[i]`。矩阵乘法的每个元素是有限个高斯整数乘积之和，所以由归纳法，任意有限因子链

\[
B=A_1A_2\cdots A_K
\]

逐元素属于 `Z[i]`。右乘置换矩阵只重排 `B` 的列，仍逐元素属于 `Z[i]`。约束 1 只缩小允许因子集合，不能破坏这个结论。

## 3. 单项格距下界

单位化 DFT 的每个元素 `f` 都满足

\[
|f|=a_N=\frac1{\sqrt N}.
\]

任取 `z in Z[i]`。若 `z=0`，则 `|f-z|=a_N`；若 `z!=0`，整数平方和给出 `|z|>=1`，再由反三角不等式，

\[
|f-z|\ge \bigl||z|-|f|\bigr|\ge 1-a_N.
\]

故每个位置都有 `|f-z|>=d_N`。因 `F_N` 有 `N^2` 个元素，任意高斯整数矩阵 `B` 满足

\[
\lVert F_N-B\rVert_F^2
=\sum_{r,c}|F_N[r,c]-B[r,c]|^2
\ge N^2d_N^2,
\]

除以题面/协议固定的 `N` 即得 `RMSE>=d_N`。这里没有使用启发式松弛，也没有把浮点枚举当成证明。

## 6. 该 K-无关界族的适用边界（补充复算）

本节回答一个自然的问题：这套"只用字母表与目标模长、不依赖 `K`"的界，能否推广到问题 2/3/4？结论是**不能**，原因纯属算术，不是没尝试。

判据两条：

1. `P_q` 中元素的最大模长 `m_q = sqrt(2)·2^(q-1) ≥ sqrt(2) ≈ 1.4142`，对每个 `q ≥ 1` 成立；
2. 单位化目标 `t = 1/sqrt(N) ≤ 1/sqrt(2) ≈ 0.7071`，对每个 `N ≥ 2` 成立。

因此 `t < m_q` 恒成立，逐项界 `max(0, t - p)` 对**所有** `q ≥ 1` 都恒为 0：该界族只能通过"强迫某些位置取 0"起作用，也就是要求**字母表内不存在模长小于 `t` 的非零元素**。这恰是 Q5 的情形，也只可能是 Q5——因为问题 5 允许把 `q` 搜索到 `q = 1`，此时 `P_1 = {0, ±1}` 给出的复系数正是高斯整数，最小非零模长为 1，而 `N = 64` 时 `t = 1/8 < 1`。对 `q ≥ 2`，字母表本身已含 `±2`，`p` 直接超过 `t`，论证在第一步就瓦解。

机器复核：`03_model/checks/verify_q234_modulus_bounds.py`（纯标准库，退出码 0，`status=PASS`）。要点：

- 逐项间隙 `t - m_q` 在全部注册 `(N, q)` 上**全为 0**，即该界对 q2/q3/q4 完全空洞；
- Q5 的 `q=1` 逐尺寸下界（独立复算路径）为 `0.292893 / 0.500000 / 0.353553 / 0.250000 / 0.176777 / 0.125000`，与第 4 节一致；
- 问题 3/4 在行上限 2 下能给出的非零数字（如 `N=4, K=1` 的 `0.176777`、`N=8, K=1` 的 `0.108253`）**全部来自行支持**，即 `sqrt(N - min(N,2^K))/N` 的换形，与字母表无关；`K ≥ 2` 之后只剩行支持项，`2^K ≥ N` 时整体归零。

**结论**：K-无关界族只在 Q5 生效；对 Q2/Q3/Q4，唯一可证的界仍是结构界，而它在 `2^K ≥ N` 时失效——这与 `BOUND_AVAILABILITY_AUDIT.md` 的判断一致，并非该审计的遗漏。论文引用时不得把 Q5 的 `d_N` 写法搬到 Q2/Q3/Q4。

另一个可复核的数值事实：`t = 1/sqrt(N) < 1` 对**所有** `N ≥ 2` 成立（不是从 `N = 64` 才开始），因此 Q5 的下界在全部注册尺寸上都为正；阈值 `0.1` 要到 `N ≥ 128` 才会与 `t` 交叉，而这已在冻结网格之外——再次说明本证书**不外推到无限尺寸族**。
